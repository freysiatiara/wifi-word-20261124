One word for your Wi-Fi: **flaky**. Home Wi-Fi works beautifully right up until the moment you actually need it — then it drops for no reason, comes back on its own, and pretends nothing happened. The funniest and most accurate description of Wi-Fi as we actually live it, and a fitting name for the sponsor's network.

## Run it

```sh
python3 main.py
```

This writes the single word to `/output/entry.txt`.
